# Tism Shredder 5000

**[Download the Windows launcher](https://github.com/iforgetalot0-web/tismshredder/releases/latest/download/TismShredderLauncher.exe)** · [Release notes and downloads](https://github.com/iforgetalot0-web/tismshredder/releases/latest)

Download **TismShredderLauncher.exe** once, keep it somewhere convenient, and open it whenever you want to play. It installs the game on first use, checks for updates before each launch, and starts the verified build. Your friend uses the same launcher. No GitHub account is required.

Windows 10/11, 64-bit. The first game download is about 617 MB, with about 1.36 GB of installed game files. Updates need additional space to keep the existing version safe while installing its replacement. Saved shifts stay on your own PC, separate from updated game files.

## Current multiplayer preview

The full existing solo game remains available. The two-player networking foundation supports hosting, joining with a code, and movement in General Operations. Shared processing and progression are still in development. This co-op preview does not save campaign progress.

## Which file do I need?

- **TismShredderLauncher.exe** — recommended; downloads, updates, and launches the game.
- **game.zip** — compiled game for manual installation.
- **channel.json** — signed update metadata for the launcher.

GitHub’s automatically generated source archives are not game downloads. This repository distributes compiled builds, not the Unity project or imported source assets.
